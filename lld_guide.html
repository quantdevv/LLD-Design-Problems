Parking Lot System
Medium State Machine Strategy Pattern Concurrency
Design a parking lot system that manages multiple floors, different vehicle types, and generates tickets. Classic state machine problem with real concurrency challenges around slot assignment.

📋 Requirements

📋 Functional Requirements
✅ Core

  • 2Vehicle parks: system finds nearest available slot, issues a ticket with entry time.
  • 3Vehicle exits: system calculates fee based on duration and vehicle type, marks slot free.
  • 4Query available slots by floor and vehicle type.
  • 5Support multiple floors.

// ── Enums ──────────────────────────────────────
enum VehicleType { MOTORCYCLE, CAR, TRUCK }
enum SlotType    { SMALL, MEDIUM, LARGE }
enum SlotStatus  { FREE, OCCUPIED }

// ── Fee Strategy (Strategy Pattern) ────────────
interface FeeStrategy {
    double calculateFee(long durationMinutes);
}

class HourlyFeeStrategy implements FeeStrategy {
    private final double ratePerHour;

    public HourlyFeeStrategy(double ratePerHour) {
        this.ratePerHour = ratePerHour;
    }

    @Override
    public double calculateFee(long durationMinutes) {
        double hours = Math.ceil(durationMinutes / 60.0);
        return hours * ratePerHour;
    }
}

// ── Parking Slot ────────────────────────────────
class ParkingSlot {
    private final String slotId;
    private final int floorNumber;
    private final int slotNumber;
    private final SlotType slotType;
    private volatile SlotStatus status;  // volatile for visibility

    public synchronized boolean park() {
        if (status == SlotStatus.FREE) {
            status = SlotStatus.OCCUPIED;
            return true;
        }
        return false;  // already taken — race condition handled
    }

    public synchronized void free() {
        status = SlotStatus.FREE;
    }

    public boolean isAvailable() { return status == SlotStatus.FREE; }
    // getters omitted for brevity
}

// ── Ticket ──────────────────────────────────────
class Ticket {
    private final String ticketId;
    private final ParkingSlot slot;
    private final VehicleType vehicleType;
    private final String licensePlate;
    private final LocalDateTime entryTime;

    public Ticket(ParkingSlot slot, VehicleType type, String plate) {
        this.ticketId = UUID.randomUUID().toString();
        this.slot = slot;
        this.vehicleType = type;
        this.licensePlate = plate;
        this.entryTime = LocalDateTime.now();
    }

    public long getDurationMinutes() {
        return ChronoUnit.MINUTES.between(entryTime, LocalDateTime.now());
    }
}

// ── Floor ───────────────────────────────────────
class Floor {
    private final int floorNumber;
    // Map: SlotType → TreeSet sorted by slotNumber for nearest-first
    private final Map<SlotType, TreeSet<ParkingSlot>> availableSlots;
    private final ReentrantLock lock = new ReentrantLock();

    public Optional<ParkingSlot> findAndOccupySlot(SlotType type) {
        lock.lock();
        try {
            TreeSet<ParkingSlot> slots = availableSlots.get(type);
            if (slots == null || slots.isEmpty()) return Optional.empty();
            ParkingSlot slot = slots.first(); // nearest slot
            if (slot.park()) {   // atomic park attempt
                slots.remove(slot);
                return Optional.of(slot);
            }
            return Optional.empty();
        } finally {
            lock.unlock();
        }
    }

    public void returnSlot(ParkingSlot slot) {
        lock.lock();
        try {
            slot.free();
            availableSlots.get(slot.getSlotType()).add(slot);
        } finally {
            lock.unlock();
        }
    }
}

// ── ParkingLot (Singleton) ───────────────────────
public class ParkingLot {
    private static volatile ParkingLot instance;
    private final List<Floor> floors;
    private final Map<String, Ticket> activeTickets;  // ticketId → Ticket
    private final FeeStrategy feeStrategy;

    // Double-checked locking Singleton
    public static ParkingLot getInstance() {
        if (instance == null) {
            synchronized (ParkingLot.class) {
                if (instance == null) {
                    instance = new ParkingLot();
                }
            }
        }
        return instance;
    }

    public Ticket park(VehicleType vehicleType, String licensePlate) {
        SlotType required = getRequiredSlotType(vehicleType);
        for (Floor floor : floors) {   // prefer ground floor first
            Optional<ParkingSlot> slot = floor.findAndOccupySlot(required);
            if (slot.isPresent()) {
                Ticket ticket = new Ticket(slot.get(), vehicleType, licensePlate);
                activeTickets.put(ticket.getTicketId(), ticket);
                return ticket;
            }
        }
        throw new ParkingFullException("No slots available for " + vehicleType);
    }

    public double exit(String ticketId) {
        Ticket ticket = activeTickets.remove(ticketId);
        if (ticket == null) throw new InvalidTicketException(ticketId);
        double fee = feeStrategy.calculateFee(ticket.getDurationMinutes());
        // return slot to its floor
        int floorIdx = ticket.getSlot().getFloorNumber();
        floors.get(floorIdx).returnSlot(ticket.getSlot());
        return fee;
    }

    private SlotType getRequiredSlotType(VehicleType v) {
        return switch (v) {
            case MOTORCYCLE -> SlotType.SMALL;
            case CAR        -> SlotType.MEDIUM;
            case TRUCK      -> SlotType.LARGE;
        };
    }
}
⚡
Concurrency Deep Dive
⚠️ Race Conditions to Handle
Double-booking a slot
Two threads both see a slot as FREE simultaneously. Fix: ReentrantLock on each Floor wraps the find-and-mark-occupied operation atomically. The slot.park() method is also synchronized as a secondary guard.
Singleton initialization race
Use double-checked locking with volatile on the instance field. Without volatile, the JVM can reorder instructions and return a partially-constructed object.
activeTickets ConcurrentModification
Use ConcurrentHashMap for the activeTickets map instead of HashMap to handle concurrent park/exit calls safely.
🔍
Design Deep Dive — Interviewer Questions
  • Q
    What if a motorcycle can park in a larger slot when small slots are full?
    Modify getRequiredSlotType to return a priority list. In park(), iterate through SlotType.SMALL → MEDIUM → LARGE until a slot is found. This is the fallback strategy.
  • Q
    How would you add hourly rate variations (weekday vs weekend)?
    The Strategy Pattern for FeeStrategy already handles this. Create a TimeSensitiveFeeStrategy that checks DayOfWeek inside calculateFee(). The ParkingLot just calls the interface.
  • Q
    How would you support reservations (pre-booking a slot)?
    Add a RESERVED status to SlotStatus enum. Add a ReservationService that creates time-bounded reservations. A background job scans for expired reservations and frees them. The findAndOccupySlot method skips RESERVED slots unless the reservation token matches.

    Elevator Control System
    Hard State Machine SCAN Algorithm Simulation
    Design an elevator system for a building with multiple elevators. Handle hall calls, destination selection, dispatch algorithm, and concurrent request handling.

    📋 Requirements

    📋 Requirements
    ✅ Core
    • 1Multiple elevators (e.g., 3 elevators, 10 floors 0–9).
    • 2Hall call: user presses UP/DOWN on a floor → system dispatches best elevator.
    • 3Destination call: user inside elevator presses a floor button.
    • 4System runs as a simulation with discrete step() ticks.
    • 5Reject invalid floor requests gracefully.

    Java 
    enum Direction     { UP, DOWN, IDLE }
enum ElevatorState { MOVING, STOPPED, IDLE }

class Elevator {
    private final int id;
    private int currentFloor;
    private Direction direction = Direction.IDLE;
    private ElevatorState state = ElevatorState.IDLE;

    // SCAN algorithm: two TreeSets for UP and DOWN stops
    private final TreeSet<Integer> upStops   = new TreeSet<>();
    private final TreeSet<Integer> downStops = new TreeSet<>(Comparator.reverseOrder());

    public synchronized void addStop(int floor, Direction dir) {
        if (dir == Direction.UP || (dir == Direction.IDLE && floor > currentFloor))
            upStops.add(floor);
        else
            downStops.add(floor);
        if (state == ElevatorState.IDLE) updateDirection();
    }

    // Called once per simulation tick
    public synchronized void step() {
        if (state == ElevatorState.IDLE) return;

        // Move one floor in current direction
        if (direction == Direction.UP)  currentFloor++;
        else                              currentFloor--;

        // Check if we stop at this floor
        TreeSet<Integer> activeSet = (direction == Direction.UP) ? upStops : downStops;
        if (activeSet.contains(currentFloor)) {
            activeSet.remove(currentFloor);
            state = ElevatorState.STOPPED;
            System.out.println("Elevator " + id + " stopped at floor " + currentFloor);
        }

        // Reverse direction if no more stops in current direction
        if (activeSet.isEmpty()) {
            if (direction == Direction.UP && !downStops.isEmpty()) {
                direction = Direction.DOWN;
                state = ElevatorState.MOVING;
            } else if (direction == Direction.DOWN && !upStops.isEmpty()) {
                direction = Direction.UP;
                state = ElevatorState.MOVING;
            } else {
                direction = Direction.IDLE;
                state = ElevatorState.IDLE;
            }
        } else {
            state = ElevatorState.MOVING;
        }
    }

    // Cost heuristic for dispatch: estimated floors to serve this request
    public int getCost(int floor, Direction requestDir) {
        if (state == ElevatorState.IDLE) return Math.abs(currentFloor - floor);
        if (direction == requestDir) {
            // Going same way — can pick up en route
            if (direction == Direction.UP && floor >= currentFloor)
                return floor - currentFloor;
            if (direction == Direction.DOWN && floor <= currentFloor)
                return currentFloor - floor;
        }
        // Must complete current direction first, then come back
        int maxUp   = upStops.isEmpty()   ? currentFloor : upStops.last();
        int maxDown = downStops.isEmpty() ? currentFloor : downStops.last();
        return (direction == Direction.UP)
            ? (maxUp - currentFloor) + (maxUp - floor)
            : (currentFloor - maxDown) + (floor - maxDown);
    }
}

class ElevatorSystem {
    private final List<Elevator> elevators;
    private final int numFloors;

    // Dispatch: pick elevator with minimum cost
    public boolean requestElevator(int floor, Direction direction) {
        if (floor < 0 || floor >= numFloors) {
            System.err.println("Invalid floor: " + floor);
            return false;
        }
        Elevator best = elevators.stream()
            .min(Comparator.comparingInt(e -> e.getCost(floor, direction)))
            .orElseThrow();
        best.addStop(floor, direction);
        return true;
    }

    // Advance all elevators one tick
    public void step() {
        elevators.forEach(Elevator::step);
    }

    // Add destination from inside elevator
    public boolean selectFloor(int elevatorId, int floor) {
        if (floor < 0 || floor >= numFloors) return false;
        elevators.get(elevatorId).addStop(floor, Direction.IDLE);
        return true;
    }
}
    ⚡
    Concurrency Deep Dive
    ⚠️ Concurrency Concerns
    addStop() vs step() race
    A new stop could be added while step() is reading the TreeSet. Both methods are synchronized on the Elevator instance to prevent this. In a real async system, use ReentrantReadWriteLock — reads of getCost can be concurrent, writes need exclusive lock.
    Dispatch selection race
    Two concurrent hall calls may both pick the same elevator as "best" before either adds the stop. In a real system, the dispatch + addStop must be atomic. Use a lock around the dispatch selection + addStop call.

    enum PackageSize      { SMALL, MEDIUM, LARGE }

class AccessToken {
    private final String code;
    private final String compartmentId;
    private final Instant expiresAt;

    public AccessToken(String compartmentId) {
        this.code = generateSecureCode();
        this.compartmentId = compartmentId;
        this.expiresAt = Instant.now().plus(7, ChronoUnit.DAYS);
    }

    public boolean isExpired() { return Instant.now().isAfter(expiresAt); }

    private String generateSecureCode() {
        return String.format("%06d", new SecureRandom().nextInt(1_000_000));
    }
}

class Compartment {
    private final String id;
    private final PackageSize size;
    private volatile CompartmentStatus status = CompartmentStatus.FREE;

    public synchronized boolean tryOccupy() {
        if (status == CompartmentStatus.FREE) {
            status = CompartmentStatus.OCCUPIED;
            return true;
        }
        return false;
    }

    public synchronized void release() { status = CompartmentStatus.FREE; }
    public boolean isFree() { return status == CompartmentStatus.FREE; }
    public PackageSize getSize() { return size; }
    public String getId() { return id; }
}

class Locker {
    // size → list of compartments for that size
    private final Map<PackageSize, List<Compartment>> compartments;
    // token code → AccessToken
    private final ConcurrentHashMap<String, AccessToken> tokenMap = new ConcurrentHashMap<>();
    private final ReentrantLock depositLock = new ReentrantLock();

    public String deposit(PackageSize size) {
        depositLock.lock();
        try {
            Compartment c = compartments.getOrDefault(size, Collections.emptyList())
                .stream()
                .filter(Compartment::isFree)
                .findFirst()
                .orElseThrow(() -> new NoSpaceException("No " + size + " compartment available"));
            c.tryOccupy();
            AccessToken token = new AccessToken(c.getId());
            tokenMap.put(token.getCode(), token);
            return token.getCode();  // return to caller (notify customer)
        } finally {
            depositLock.unlock();
        }
    }

    public void pickup(String tokenCode) {
        AccessToken token = tokenMap.get(tokenCode);
        if (token == null)    throw new InvalidTokenException("Token not found");
        if (token.isExpired()) throw new ExpiredTokenException("Token expired");
        // find compartment, open it, release
        findCompartmentById(token.getCompartmentId()).release();
        tokenMap.remove(tokenCode);
    }

    // Staff cleanup: open all compartments with expired tokens
    public List<String> clearExpiredCompartments() {
        return tokenMap.entrySet().stream()
            .filter(e -> e.getValue().isExpired())
            .map(e -> {
                findCompartmentById(e.getValue().getCompartmentId()).release();
                tokenMap.remove(e.getKey());
                return e.getValue().getCompartmentId();
            })
            .collect(Collectors.toList());
    }
}
    🔍
    Deep Dive — Key Design Decisions
  • Q
    Why is Package not an entity?
    Package is external to the locker system — it belongs to Amazon's fulfillment system. The locker only cares about the package's size, which is an input parameter, not a stored entity. This is a common interview trap: not every noun deserves a class.
  • Q
    How do you prevent two drivers depositing simultaneously to the same slot?
    The ReentrantLock depositLock wraps the find-and-occupy operation. Additionally, tryOccupy() on the compartment is synchronized as a double guard. Only one thread can occupy a slot at a time.

    Medium State Machine State Pattern
    Classic state machine problem. The machine transitions through well-defined states: Idle → HasMoney → Dispensing → Change. The State Pattern eliminates massive if-else chains.

    // ── State Interface ─────────────────────────────
interface VendingState {

// ── Idle State ─────────────────────────────────
class IdleState implements VendingState {
    @Override
    public void insertMoney(VendingMachine vm, double amount) {
        vm.addBalance(amount);
        vm.setState(vm.getHasMoneyState());  // transition
        System.out.println("Money inserted: $" + amount);
    }

    @Override
    public void selectItem(VendingMachine vm, String code) {
        System.out.println("Please insert money first.");
    }
    @Override public void dispense(VendingMachine vm)    { System.out.println("No item selected."); }
    @Override public void cancel(VendingMachine vm)      { System.out.println("Nothing to cancel."); }
}

// ── Has Money State ────────────────────────────
class HasMoneyState implements VendingState {
    @Override
    public void insertMoney(VendingMachine vm, double amount) {
        vm.addBalance(amount);
        System.out.println("Added $" + amount + ". Balance: $" + vm.getBalance());
    }

    @Override
    public void selectItem(VendingMachine vm, String code) {
        Item item = vm.getInventory().get(code);
        if (item == null)          { System.out.println("Item not found.");  return; }
        if (item.getQuantity() == 0) { System.out.println("Out of stock.");    return; }
        if (vm.getBalance() < item.getPrice()) {
            System.out.println("Insufficient funds. Need $" + (item.getPrice() - vm.getBalance()));
            return;
        }
        vm.setSelectedItem(item);
        vm.setState(vm.getDispensingState());
        vm.getState().dispense(vm);  // auto-dispense
    }

    @Override public void dispense(VendingMachine vm)  { System.out.println("Select an item first."); }
    @Override
    public void cancel(VendingMachine vm) {
        System.out.println("Returning $" + vm.getBalance());
        vm.setBalance(0);
        vm.setState(vm.getIdleState());
    }
}

// ── Dispensing State ───────────────────────────
class DispensingState implements VendingState {
    @Override
    public void dispense(VendingMachine vm) {
        Item item = vm.getSelectedItem();
        item.decrementQuantity();
        double change = vm.getBalance() - item.getPrice();
        vm.setBalance(0);
        System.out.println("Dispensing: " + item.getName());
        if (change > 0) System.out.println("Change: $" + change);
        vm.setState(vm.getIdleState());
    }

    @Override public void insertMoney(VendingMachine vm, double a) { System.out.println("Dispensing..."); }
    @Override public void selectItem(VendingMachine vm, String c)  { System.out.println("Dispensing..."); }
    @Override public void cancel(VendingMachine vm)               { System.out.println("Cannot cancel."); }
}

// ── Machine Context ────────────────────────────
class VendingMachine {
    private VendingState currentState;
    private double balance;
    private Item selectedItem;
    private final Map<String, Item> inventory = new ConcurrentHashMap<>();
    // State instances (flyweight)
    private final VendingState idleState = new IdleState();
    private final VendingState hasMoneyState = new HasMoneyState();
    private final VendingState dispensingState = new DispensingState();

    public VendingMachine() { currentState = idleState; }

    // Delegated to current state
    public void insertMoney(double amount)   { currentState.insertMoney(this, amount); }
    public void selectItem(String code)     { currentState.selectItem(this, code); }
    public void cancel()                      { currentState.cancel(this); }
    // setters/getters for state transitions omitted for brevity
}
    State Pattern key insight: Each state class encapsulates all valid behavior for that state. Invalid operations print an error and return — they never throw. The machine's currentState reference switches atomically. No giant switch/if-else anywhere.

    💻 Code Implementation

    // ── Bill Dispenser (Chain of Responsibility) ───
abstract class BillHandler {
    protected BillHandler next;
    protected final int denomination;
    protected int count;

    public BillHandler(int denomination, int count) {
        this.denomination = denomination;
        this.count = count;
    }

    public BillHandler setNext(BillHandler next) {
        this.next = next;
        return next;
    }

    public Map<Integer, Integer> dispense(int amount) {
        Map<Integer, Integer> bills = new LinkedHashMap<>();
        int numBills = Math.min(amount / denomination, count);
        if (numBills > 0) {
            bills.put(denomination, numBills);
            count -= numBills;
            amount -= numBills * denomination;
        }
        if (amount > 0 && next != null) {
            bills.putAll(next.dispense(amount));
        }
        return bills;
    }

    public boolean canDispense(int amount) {
        int remaining = amount;
        BillHandler current = this;
        while (current != null) {
            remaining -= Math.min(remaining / current.denomination, current.count) * current.denomination;
            current = current.next;
        }
        return remaining == 0;
    }
}

// ── Account Service ────────────────────────────
class AccountService {
    private final AccountRepository repo;

    // Optimistic locking via @Version in JPA or check-and-update SQL
    public boolean withdraw(String accountId, double amount) {
        // SQL: UPDATE accounts SET balance = balance - ? 
        //      WHERE account_id = ? AND balance >= ? AND locked = false
        int rowsAffected = repo.decrementBalance(accountId, amount);
        return rowsAffected > 0;
    }

    public boolean verifyPin(String cardNumber, String pin) {
        Account account = repo.findByCardNumber(cardNumber);
        if (account.isLocked()) throw new AccountLockedException();
        if (!BCrypt.checkpw(pin, account.getPinHash())) {
            repo.incrementPinAttempts(account.getId());
            if (account.getPinAttempts() + 1 >= 3) {
                repo.lockAccount(account.getId());
                throw new AccountLockedException("Too many failed attempts");
            }
            return false;
        }
        repo.resetPinAttempts(account.getId());
        return true;
    }
}

// ── ATM Machine ───────────────────────────────
class ATM {
    private ATMState currentState = new IdleState();
    private String currentCardNumber;
    private Account authenticatedAccount;
    private final BillHandler cashDispenser;
    private final AccountService accountService;

    public ATM(AccountService svc) {
        this.accountService = svc;
        // Set up chain: $100 → $50 → $20 → $10
        BillHandler h100 = new BillHandler(100, 50) {};
        BillHandler h50  = new BillHandler(50,  100) {};
        BillHandler h20  = new BillHandler(20,  200) {};
        BillHandler h10  = new BillHandler(10,  500) {};
        h100.setNext(h50).setNext(h20).setNext(h10);
        this.cashDispenser = h100;
    }

    public void withdraw(int amount) {
        if (!cashDispenser.canDispense(amount))
            throw new InsufficientCashException("ATM cannot dispense $" + amount);
        if (!accountService.withdraw(authenticatedAccount.getId(), amount))
            throw new InsufficientFundsException();
        // Only dispense cash after successful DB debit
        Map<Integer, Integer> bills = cashDispenser.dispense(amount);
        System.out.println("Dispensing: " + bills);
    }
}
    ⚠️ Critical: TOCTOU Race on Balance
    Check-then-act vulnerability
    Never do: if (balance >= amount) { balance -= amount; } — two threads can both pass the check before either subtracts. Fix: use a single atomic SQL UPDATE accounts SET balance = balance - ? WHERE balance >= ? AND account_id = ?. Check rows affected = 1. If 0, balance was insufficient.

    Rate Limiter
    Hard Token Bucket Sliding Window High Concurrency
    Implement multiple rate limiting algorithms. Highly concurrent — multiple threads call allowRequest() simultaneously. Atomic operations are critical.

    💻 Code Implementation — All 3 Algorithms

    Java 
    // ── Interface ──────────────────────────────────
interface RateLimiter {
    boolean allowRequest(String clientId);
}

// ════════════════════════════════════════════════
// ALGORITHM 1: Token Bucket
// Best for: bursty traffic (allows burst up to bucketSize)
// ════════════════════════════════════════════════
class TokenBucketRateLimiter implements RateLimiter {
    private final int capacity;
    private final double refillRatePerSecond;
    // Per-client bucket state
    private final ConcurrentHashMap<String, double[]> buckets = new ConcurrentHashMap<>();
    private final ConcurrentHashMap<String, long[]> lastRefill = new ConcurrentHashMap<>();

    public TokenBucketRateLimiter(int capacity, double refillPerSec) {
        this.capacity = capacity;
        this.refillRatePerSecond = refillPerSec;
    }

    @Override
    public synchronized boolean allowRequest(String clientId) {
        // Initialize bucket if first request
        buckets.putIfAbsent(clientId, new double[] {capacity});
        lastRefill.putIfAbsent(clientId, new long[] {System.currentTimeMillis()});

        long now = System.currentTimeMillis();
        long elapsed = now - lastRefill.get(clientId)[0];
        lastRefill.get(clientId)[0] = now;

        // Refill tokens based on elapsed time
        double[] tokens = buckets.get(clientId);
        tokens[0] = Math.min(capacity, tokens[0] + (elapsed / 1000.0) * refillRatePerSecond);

        if (tokens[0] >= 1.0) {
            tokens[0]--;
            return true;  // Request allowed
        }
        return false;  // Rate limited
    }
}

// ════════════════════════════════════════════════
// ALGORITHM 2: Fixed Window Counter
// Best for: simple per-minute/hour limits
// ════════════════════════════════════════════════
class FixedWindowRateLimiter implements RateLimiter {
    private final int maxRequests;
    private final long windowSizeMs;
    private final ConcurrentHashMap<String, AtomicInteger> counters = new ConcurrentHashMap<>();
    private final ConcurrentHashMap<String, long[]> windowStart = new ConcurrentHashMap<>();

    @Override
    public boolean allowRequest(String clientId) {
        long now = System.currentTimeMillis();
        windowStart.putIfAbsent(clientId, new long[] {now});
        counters.putIfAbsent(clientId, new AtomicInteger(0));

        // Reset window if expired
        if (now - windowStart.get(clientId)[0] >= windowSizeMs) {
            windowStart.get(clientId)[0] = now;
            counters.get(clientId).set(0);
        }
        // Atomic increment and check
        return counters.get(clientId).incrementAndGet() <= maxRequests;
    }
}

// ════════════════════════════════════════════════
// ALGORITHM 3: Sliding Window Log
// Best for: strict accuracy (no boundary spikes)
// ════════════════════════════════════════════════
class SlidingWindowLogRateLimiter implements RateLimiter {
    private final int maxRequests;
    private final long windowSizeMs;
    // Per-client: sorted deque of timestamps
    private final ConcurrentHashMap<String, ArrayDeque<Long>> logs = new ConcurrentHashMap<>();

    @Override
    public synchronized boolean allowRequest(String clientId) {
        long now = System.currentTimeMillis();
        logs.putIfAbsent(clientId, new ArrayDeque<>());
        ArrayDeque<Long> log = logs.get(clientId);

        // Remove timestamps outside the window
        while (!log.isEmpty() && now - log.peekFirst() > windowSizeMs) {
            log.pollFirst();
        }

        if (log.size() < maxRequests) {
            log.addLast(now);
            return true;
        }
        return false;
    }
}
    AlgorithmMemoryAccuracyBurst HandlingBest For
    Token BucketO(1)Approximate✅ Allows burstsAPIs with burst tolerance
    Fixed WindowO(1)Has boundary spike❌ 2x at boundarySimple per-hour limits
    Sliding Window LogO(requests)✅ Exact❌ No burstStrict API rate limiting
    ⚠️ Concurrency — Why This Is Hard
    Fixed Window — Lost Updates
    Use AtomicInteger.incrementAndGet() — not counter++. The non-atomic version has a classic read-modify-write race: two threads read 99, both write 100, but the true count should be 101.
    Token Bucket / Sliding Log — Lock Granularity
    Lock per client ID, not on the entire map. Use ConcurrentHashMap.compute(clientId, ...) for atomic per-key operations, or maintain a per-client ReentrantLock via a ConcurrentHashMap<String, Lock>. Global synchronization is a throughput killer.

    Distributed Task Scheduler

    class ScheduledTask implements Comparable<ScheduledTask> {
    private final String taskId;
    private final Runnable task;
    private final long scheduledTimeMs;   // when to run
    private final long intervalMs;         // 0 = one-time
    private final int priority;            // higher = more urgent
    private volatile boolean cancelled = false;

    @Override
    public int compareTo(ScheduledTask other) {
        // Earlier time first; break ties by priority (higher = first)
        int cmp = Long.compare(this.scheduledTimeMs, other.scheduledTimeMs);
        return cmp != 0 ? cmp : Integer.compare(other.priority, this.priority);
    }

    public boolean isRecurring()  { return intervalMs > 0; }
    public void    cancel()       { cancelled = true; }
    public boolean isCancelled() { return cancelled; }
}

class TaskScheduler {
    // Min-heap: task with earliest scheduledTime is at front
    private final PriorityBlockingQueue<ScheduledTask> queue = new PriorityBlockingQueue<>();
    private final ExecutorService workerPool;
    private final ScheduledExecutorService pollerThread;
    private volatile boolean running = false;

    public TaskScheduler(int threadPoolSize) {
        this.workerPool = Executors.newFixedThreadPool(threadPoolSize);
        this.pollerThread = Executors.newSingleThreadScheduledExecutor();
    }

    public void start() {
        running = true;
        // Poll every 10ms for tasks ready to run
        pollerThread.scheduleAtFixedRate(this::pollAndExecute, 0, 10, TimeUnit.MILLISECONDS);
    }

    private void pollAndExecute() {
        long now = System.currentTimeMillis();
        while (!queue.isEmpty()) {
            ScheduledTask task = queue.peek();
            if (task == null || task.getScheduledTimeMs() > now) break;

            task = queue.poll();  // remove it
            if (task == null) break;
            if (task.isCancelled()) continue;

            final ScheduledTask finalTask = task;
            workerPool.submit(() -> {
                try {
                    finalTask.getTask().run();
                } catch (Exception e) {
                    System.err.println("Task failed: " + finalTask.getTaskId() + " - " + e.getMessage());
                }
                // Re-schedule if recurring
                if (finalTask.isRecurring() && !finalTask.isCancelled()) {
                    ScheduledTask next = finalTask.withNextScheduledTime(
                        finalTask.getScheduledTimeMs() + finalTask.getIntervalMs()
                    );
                    queue.add(next);
                }
            });
        }
    }

    public ScheduledTask schedule(Runnable task, long delayMs, int priority) {
        ScheduledTask st = new ScheduledTask(task, System.currentTimeMillis() + delayMs, 0, priority);
        queue.add(st);
        return st;
    }

    public ScheduledTask scheduleRecurring(Runnable task, long initialDelayMs, long intervalMs) {
        ScheduledTask st = new ScheduledTask(task, System.currentTimeMillis() + initialDelayMs, intervalMs, 5);
        queue.add(st);
        return st;
    }

    public void shutdown() {
        running = false;
        pollerThread.shutdown();
        workerPool.shutdown();
    }
}
    Why PriorityBlockingQueue? It's thread-safe, unbounded, and provides O(log n) insert/extract. The queue's natural order (our compareTo) ensures the earliest task is always at the head. The peek() without poll() lets us check without consuming until we're sure the task is ready.

    Thread-Safe Blocking Queue
    Hard Core Concurrency Monitor Pattern
    Implement a bounded blocking queue from scratch using only locks and condition variables. This is the core of producer-consumer pattern and tests deep understanding of Java concurrency primitives.

    💻 Code Implementation

    Java 
    class BoundedBlockingQueue<T> {
    private final Queue<T> queue;
    private final int capacity;
    private final ReentrantLock lock = new ReentrantLock();
    private final Condition notFull  = lock.newCondition(); // signal when space available
    private final Condition notEmpty = lock.newCondition(); // signal when item available

    public BoundedBlockingQueue(int capacity) {
        this.capacity = capacity;
        this.queue = new LinkedList<>();
    }

    // Producer: blocks if full
    public void put(T item) throws InterruptedException {
        lock.lock();
        try {
            while (queue.size() == capacity) {
                notFull.await();  // release lock, wait for signal
            }
            queue.add(item);
            notEmpty.signal();  // wake one waiting consumer
        } finally {
            lock.unlock();
        }
    }

    // Consumer: blocks if empty
    public T take() throws InterruptedException {
        lock.lock();
        try {
            while (queue.isEmpty()) {
                notEmpty.await();  // release lock, wait for signal
            }
            T item = queue.poll();
            notFull.signal();   // wake one waiting producer
            return item;
        } finally {
            lock.unlock();
        }
    }

    // Non-blocking offer with timeout
    public boolean offer(T item, long timeout, TimeUnit unit) throws InterruptedException {
        lock.lock();
        try {
            long nanos = unit.toNanos(timeout);
            while (queue.size() == capacity) {
                if (nanos <= 0) return false;  // timed out
                nanos = notFull.awaitNanos(nanos);
            }
            queue.add(item);
            notEmpty.signal();
            return true;
        } finally {
            lock.unlock();
        }
    }

    public int size()     { lock.lock(); try { return queue.size(); } finally { lock.unlock(); } }
    public boolean isEmpty() { return size() == 0; }
    public boolean isFull()  { return size() == capacity; }
}
    ⚠️ Critical: Use while, not if
    Always use while (condition) { await(); } — never if (condition) { await(); }. This is because spurious wakeups can occur: a thread may wake from await() without being signaled. The while re-checks the condition and waits again if it's still true. Using if here is a classic concurrency bug.
    Why two Condition variables? Using a single notifyAll() would wake every waiting thread — both producers and consumers. With two Conditions, notFull.signal() wakes only a producer and notEmpty.signal() wakes only a consumer. This halves unnecessary wakeups and improves throughput.

    private final String name;
    // subscriberId → Subscriber

    private final List<Message> log = Collections.synchronizedList(new ArrayList<>());
    private final ExecutorService deliveryPool = Executors.newCachedThreadPool();

    }

    public void publish(Message message) {
        log.add(message);  // append to log
        // Async delivery to each subscriber
        subscribers.values().forEach(sub ->
            deliveryPool.submit(() -> {
                try {
                    sub.onMessage(message);
                } catch (Exception e) {
                    System.err.println("Delivery failed to " + sub.getId() + ": " + e.getMessage());
                    // In real system: retry queue or DLQ
                }
            })
        );
    }

    // Replay messages from offset (for new subscribers)
    public void replayFrom(Subscriber sub, int fromOffset) {
        synchronized (log) {
            log.subList(Math.max(0, fromOffset), log.size())
               .forEach(msg -> deliveryPool.submit(() -> sub.onMessage(msg)));
        }
    }
}

    class ConnectionPool {
    private final int maxSize;
    private final int minSize;
    private final long connectionTimeoutMs;
    private final String jdbcUrl;

    // Available connections
    private final ArrayBlockingQueue<PooledConnection> available;
    // All connections (for lifecycle management)
    private final Set<PooledConnection> allConnections = ConcurrentHashMap.newKeySet();
    private final AtomicInteger totalConnections = new AtomicInteger(0);
    private volatile boolean shutdown = false;

    public ConnectionPool(int minSize, int maxSize, long timeoutMs, String jdbcUrl) {
        this.minSize = minSize;
        this.maxSize = maxSize;
        this.connectionTimeoutMs = timeoutMs;
        this.jdbcUrl = jdbcUrl;
        this.available = new ArrayBlockingQueue<>(maxSize);
        initializeMinConnections();
        startHealthCheckThread();
    }

    private void initializeMinConnections() {
        for (int i = 0; i < minSize; i++) {
            PooledConnection conn = createConnection();
            available.offer(conn);
            allConnections.add(conn);
        }
    }

    // Acquire a connection — blocks up to timeout
    public PooledConnection acquire() throws Exception {
        if (shutdown) throw new IllegalStateException("Pool is shut down");

        PooledConnection conn = available.poll();
        if (conn != null) {
            if (conn.isValid()) {
                conn.markInUse();
                return conn;
            }
            // Stale connection — discard and create new
            allConnections.remove(conn);
            totalConnections.decrementAndGet();
        }

        // Try to create a new connection if under max
        if (totalConnections.get() < maxSize) {
            if (totalConnections.incrementAndGet() <= maxSize) {
                conn = createConnection();
                allConnections.add(conn);
                conn.markInUse();
                return conn;
            }
            totalConnections.decrementAndGet();  // undo increment
        }

        // Wait for a connection to be returned
        conn = available.poll(connectionTimeoutMs, TimeUnit.MILLISECONDS);
        if (conn == null) throw new TimeoutException("Timeout waiting for connection");
        conn.markInUse();
        return conn;
    }

    // Release a connection back to pool
    public void release(PooledConnection conn) {
        if (conn == null) return;
        conn.markAvailable();
        if (shutdown || !conn.isValid()) {
            allConnections.remove(conn);
            totalConnections.decrementAndGet();
            conn.closePhysically();
            return;
        }
        if (!available.offer(conn)) {
            // Pool full — close the excess connection
            allConnections.remove(conn);
            totalConnections.decrementAndGet();
            conn.closePhysically();
        }
    }

    // Health check: evict stale, ensure min connections
    private void startHealthCheckThread() {
        ScheduledExecutorService checker = Executors.newSingleThreadScheduledExecutor();
        checker.scheduleAtFixedRate(() -> {
            if (shutdown) return;
            int toCreate = minSize - totalConnections.get();
            for (int i = 0; i < toCreate; i++) {
                try {
                    PooledConnection conn = createConnection();
                    allConnections.add(conn);
                    available.offer(conn);
                    totalConnections.incrementAndGet();
                } catch (Exception e) {
                    System.err.println("Health check: failed to create connection");
                }
            }
        }, 30, 30, TimeUnit.SECONDS);
    }

    // Try-with-resources support
    public AutoCloseable withConnection(Consumer<PooledConnection> action) throws Exception {
        PooledConnection conn = acquire();
        return () -> {
            action.accept(conn);
            release(conn);
        };
    }

    private PooledConnection createConnection() {
        return new PooledConnection(DriverManager.getConnection(jdbcUrl), this);
    }
}

record Position(int row, int col) {
    public boolean isValid() { return row >= 0 && row < 8 && col >= 0 && col < 8; }

// ── Abstract Piece ─────────────────────────────
abstract class Piece {
    protected final Color color;
    protected Position position;
    protected boolean hasMoved = false;

    public Piece(Color color, Position position) {
        this.color = color; this.position = position;
    }

    // Template Method: subclasses define valid moves
    public abstract List<Position> getValidMoves(Board board);

    public boolean canMoveTo(Position target, Board board) {
        return getValidMoves(board).contains(target);
    }
}

// ── Rook ──────────────────────────────────────
class Rook extends Piece {
    public Rook(Color color, Position pos) { super(color, pos); }

    @Override
    public List<Position> getValidMoves(Board board) {
        return getSlidingMoves(board, new int[][] {{1,0},{-1,0},{0,1},{0,-1}});
    }

    protected List<Position> getSlidingMoves(Board board, int[][] directions) {
        List<Position> moves = new ArrayList<>();
        for (int[] dir : directions) {
            Position curr = position.offset(dir[0], dir[1]);
            while (curr.isValid()) {
                Piece occupant = board.getPieceAt(curr);
                if (occupant == null) {
                    moves.add(curr);
                } else {
                    if (occupant.getColor() != color) moves.add(curr); // capture
                    break;  // blocked
                }
                curr = curr.offset(dir[0], dir[1]);
            }
        }
        return moves;
    }
}

// ── Knight ────────────────────────────────────
class Knight extends Piece {
    private static final int[][] MOVES = {{-2,-1},{-2,1},{2,-1},{2,1},{-1,-2},{1,-2},{-1,2},{1,2}};
    public Knight(Color color, Position pos) { super(color, pos); }

    @Override
    public List<Position> getValidMoves(Board board) {
        return Arrays.stream(MOVES)
            .map(m -> position.offset(m[0], m[1]))
            .filter(Position::isValid)
            .filter(p -> board.getPieceAt(p) == null || board.getPieceAt(p).getColor() != color)
            .collect(Collectors.toList());
    }
}

// ── Move Command (Command Pattern = supports undo) ──
class MoveCommand {
    private final Piece piece;
    private final Position from, to;
    private Piece capturedPiece;
    private boolean hadMoved;

    public void execute(Board board) {
        capturedPiece = board.getPieceAt(to);
        hadMoved = piece.hasMoved;
        board.movePiece(piece, to);
        piece.hasMoved = true;
    }

    public void undo(Board board) {
        board.movePiece(piece, from);
        piece.hasMoved = hadMoved;
        if (capturedPiece != null) board.placePiece(capturedPiece, to);
    }
}

// ── Game ──────────────────────────────────────
class ChessGame {
    private final Board board;
    private Color currentTurn = Color.WHITE;
    private final Deque<MoveCommand> moveHistory = new ArrayDeque<>();
    private GameStatus status = GameStatus.IN_PROGRESS;

    public boolean makeMove(Color playerColor, Position from, Position to) {
        if (status != GameStatus.IN_PROGRESS)   throw new GameOverException();
        if (playerColor != currentTurn)           throw new WrongTurnException();

        Piece piece = board.getPieceAt(from);
        if (piece == null || piece.getColor() != playerColor) return false;
        if (!piece.canMoveTo(to, board)) return false;

        MoveCommand cmd = new MoveCommand(piece, from, to);
        cmd.execute(board);

        // Reject if own king in check after move
        if (board.isInCheck(playerColor)) {
            cmd.undo(board);
            throw new MoveLeavesKingInCheckException();
        }

        moveHistory.push(cmd);
        checkGameStatus();
        currentTurn = (currentTurn == Color.WHITE) ? Color.BLACK : Color.WHITE;
        return true;
    }

    public void undoLastMove() {
        if (!moveHistory.isEmpty()) moveHistory.pop().undo(board);
    }
}

    // ── Split Types (Visitor Pattern) ──────────────
interface SplitStrategy {
    Map<String, Double> computeSplits(double totalAmount, List<String> participants);
}

class EqualSplit implements SplitStrategy {
    @Override
    public Map<String, Double> computeSplits(double total, List<String> participants) {
        double share = total / participants.size();
        return participants.stream().collect(Collectors.toMap(id -> id, id -> share));
    }
}

class PercentageSplit implements SplitStrategy {
    private final Map<String, Double> percentages;  // userId → percentage
    @Override
    public Map<String, Double> computeSplits(double total, List<String> participants) {
        double sumPct = percentages.values().stream().mapToDouble(Double::doubleValue).sum();
        if (Math.abs(sumPct - 100.0) > 0.01) throw new InvalidSplitException("Percentages must sum to 100");
        return percentages.entrySet().stream()
            .collect(Collectors.toMap(Map.Entry::getKey, e -> total * e.getValue() / 100.0));
    }
}

// ── Expense Service ────────────────────────────
class ExpenseService {
    private final ExpenseRepository repo;

    public void addExpense(String groupId, String paidBy, double amount,
                           List<String> participants, SplitStrategy strategy) {
        Map<String, Double> splits = strategy.computeSplits(amount, participants);
        // Validate splits sum to total
        double splitSum = splits.values().stream().mapToDouble(Double::doubleValue).sum();
        if (Math.abs(splitSum - amount) > 0.01) throw new InvalidSplitException("Splits don't match total");
        repo.saveExpense(groupId, paidBy, amount, splits);
    }

    // Returns net balance for each user (positive = owed, negative = owes)
    public Map<String, Double> getNetBalances(String groupId) {
        Map<String, Double> balances = new HashMap<>();
        repo.getExpenses(groupId).forEach(expense -> {
            // Payer gets credit
            balances.merge(expense.getPaidBy(), expense.getTotalAmount(), Double::sum);
            // Each participant owes their split
            expense.getSplits().forEach((userId, owed) ->
                balances.merge(userId, -owed, Double::sum));
        });
        return balances;
    }
}

// ── Debt Simplification Algorithm ─────────────
// O(n log n) greedy: reduces N*(N-1) debts to ≤ N-1 transactions
// Key insight: compute net balance per person, then greedily 
// match the biggest creditor with biggest debtor
class DebtSimplifier {
    public List<Transaction> simplify(Map<String, Double> netBalances) {
        List<Transaction> result = new ArrayList<>();

        // Max heap for creditors (positive balance), min heap for debtors
        PriorityQueue<double[]> creditors = new PriorityQueue<>((a,b) -> Double.compare(b[0], a[0]));
        PriorityQueue<double[]> debtors   = new PriorityQueue<>((a,b) -> Double.compare(a[0], b[0]));

        netBalances.forEach((userId, balance) -> {
            if (balance > 0.01)  creditors.add(new double[] {balance,  userId.hashCode()});
            if (balance < -0.01) debtors.add(  new double[] {balance,  userId.hashCode()});
        });

        while (!creditors.isEmpty() && !debtors.isEmpty()) {
            double[] creditor = creditors.poll();
            double[] debtor   = debtors.poll();
            double settle = Math.min(creditor[0], -debtor[0]);
            result.add(new Transaction(getUserId(debtor), getUserId(creditor), settle));
            double remCredit = creditor[0] - settle;
            double remDebt   = debtor[0]   + settle;
            if (remCredit > 0.01) creditors.add(new double[] {remCredit, creditor[1]});
            if (remDebt < -0.01)  debtors.add(  new double[] {remDebt,   debtor[1]});
        }
        return result;
    }
}
    Debt simplification is the hardest part. Example: A owes B $10, B owes C $10, C owes A $10 → after simplification: zero transactions (they all cancel). The greedy algorithm always produces ≤ N-1 transactions for N people — optimal result.

    class BookingService {

    // ── Strategy 1: Short-lived hold (best for real systems) ──
    // SQL: UPDATE seats SET status='HELD', held_until=NOW()+10min, version=version+1
    //      WHERE seat_id=? AND status='AVAILABLE' AND version=?
    public String holdSeat(String seatId, String userId) {
        Seat seat = seatRepo.findById(seatId).orElseThrow();
        if (seat.getStatus() != SeatStatus.AVAILABLE) {
            throw new SeatNotAvailableException(seatId);
        }
        // Optimistic locking via version check in SQL
        int rows = seatRepo.holdWithVersion(seatId, seat.getVersion(), userId,
                                             Instant.now().plus(10, ChronoUnit.MINUTES));
        if (rows == 0) throw new ConcurrentBookingException("Seat just taken by another user");

        // Create pending booking
        return bookingRepo.createPending(userId, seatId).getBookingId();
    }

    // ── Confirm booking after payment ────────────
    public void confirmBooking(String bookingId, String paymentToken) {
        Booking booking = bookingRepo.findById(bookingId).orElseThrow();
        if (booking.getStatus() != BookingStatus.PENDING) return;

        // Check hold not expired
        for (String seatId : booking.getSeatIds()) {
            Seat seat = seatRepo.findById(seatId).orElseThrow();
            if (seat.getStatus() != SeatStatus.HELD || seat.getHeldUntil().isBefore(Instant.now())) {
                throw new HoldExpiredException("Hold expired for seat: " + seatId);
            }
        }

        // Process payment (external call)
        paymentService.charge(booking.getUserId(), booking.getTotalPrice(), paymentToken);

        // Atomic: mark seats BOOKED + booking CONFIRMED
        try {
            booking.getSeatIds().forEach(sid -> seatRepo.markBooked(sid));
            bookingRepo.confirm(bookingId);
        } catch (Exception e) {
            // Refund if confirmation fails after payment
            paymentService.refund(booking.getUserId(), booking.getTotalPrice());
            throw e;
        }
    }

    // ── Background job: release expired holds ─────
    @Scheduled(fixedRate = 30_000)  // every 30 seconds
    public void releaseExpiredHolds() {
        // SQL: UPDATE seats SET status='AVAILABLE', held_until=NULL
        //      WHERE status='HELD' AND held_until < NOW()
        int released = seatRepo.releaseExpiredHolds(Instant.now());
        // Also cancel associated pending bookings
        bookingRepo.cancelPendingForReleasedSeats();
        System.out.println("Released " + released + " expired seat holds");
    }
}
    ⚠️ Race Condition Strategies Compared
    Optimistic Locking (recommended)
    Read version, update with WHERE version = old_version. If 0 rows updated, someone else won. No locks held during read. Best for low-contention situations. This is what the code above uses.
    Pessimistic Locking (SELECT FOR UPDATE)
    Lock the seat row on read. Prevents all concurrent access. Use for high-value events (concert tickets going on sale) where contention is extremely high and you need guaranteed serialization. Risk: deadlock if locking multiple seats.
    Redis Distributed Lock (SETNX + TTL)
    SET lock:seat:{id} {userId} NX EX 10 — atomic set-if-not-exists with 10s TTL. Useful when DB is not the bottleneck but you need cross-service locking without DB row locks.

class LibraryService {
    private static final double FINE_PER_DAY = 0.50;
    private static final int LOAN_DURATION_DAYS = 14;
    private static final int MAX_LOANS_PER_MEMBER = 5;

    public Loan borrowBook(String memberId, String isbn) {
        // Check active loan count
        int activeLoans = loanRepo.countActiveLoans(memberId);
        if (activeLoans >= MAX_LOANS_PER_MEMBER)
            throw new MaxLoansExceededException("Member has " + activeLoans + " loans");

        // Check member has no outstanding fines
        double unpaidFines = fineRepo.getTotalUnpaidFines(memberId);
        if (unpaidFines > 0) throw new UnpaidFinesException(unpaidFines);

        // Atomic decrement — SQL: UPDATE books SET available_copies = available_copies - 1
        //                         WHERE isbn=? AND available_copies > 0
        int rows = bookRepo.decrementAvailable(isbn);
        if (rows == 0) {
            // Book unavailable — check for reservations
            reservationRepo.createReservation(memberId, isbn);
            throw new BookNotAvailableException("Added to reservation queue");
        }

        return loanRepo.create(memberId, isbn,
            LocalDate.now(), LocalDate.now().plusDays(LOAN_DURATION_DAYS));
    }

    public double returnBook(String loanId) {
        Loan loan = loanRepo.findById(loanId).orElseThrow();
        if (loan.getReturnedDate() != null) throw new AlreadyReturnedException();

        double fine = calculateFine(loan);
        loanRepo.markReturned(loanId, LocalDate.now(), fine);
        bookRepo.incrementAvailable(loan.getIsbn());

        // Notify first member in reservation queue
        reservationRepo.findFirstWaiting(loan.getIsbn()).ifPresent(reservation -> {
            notificationService.notifyBookAvailable(reservation.getMemberId(), loan.getIsbn());
            reservationRepo.markReady(reservation.getId());
        });

        return fine;
    }

    private double calculateFine(Loan loan) {
        long daysLate = ChronoUnit.DAYS.between(loan.getDueDate(), LocalDate.now());
        return daysLate > 0 ? daysLate * FINE_PER_DAY : 0.0;
    }

    // Book search using criteria builder
    public List<Book> searchBooks(BookSearchCriteria criteria) {
        return bookRepo.findByCriteria(criteria);  // dynamic query building
    }
}

    // ── Order Status State Machine ────────────────
enum OrderStatus {
    PLACED, CONFIRMED, PREPARING, READY_FOR_PICKUP, PICKED_UP, DELIVERED, CANCELLED;

    private static final Map<OrderStatus, Set<OrderStatus>> TRANSITIONS = Map.of(
        PLACED,            Set.of(CONFIRMED, CANCELLED),
        CONFIRMED,         Set.of(PREPARING, CANCELLED),
        PREPARING,         Set.of(READY_FOR_PICKUP),
        READY_FOR_PICKUP,  Set.of(PICKED_UP),
        PICKED_UP,         Set.of(DELIVERED),
        DELIVERED,         Set.of(),
        CANCELLED,         Set.of()
    );

    public boolean canTransitionTo(OrderStatus next) {
        return TRANSITIONS.getOrDefault(this, Set.of()).contains(next);
    }
}

// ── Order Service ─────────────────────────────
class OrderService {
    private final OrderRepository orderRepo;
    private final DeliveryAgentService agentService;
    private final NotificationService notificationService;
    private final PaymentService paymentService;

    public Order placeOrder(String customerId, String restaurantId,
                            List<OrderItem> items, Address deliveryAddress) {
        // Validate menu items still available and prices match
        double total = validateAndCalculateTotal(restaurantId, items);

        // Create order in PLACED state
        Order order = orderRepo.create(customerId, restaurantId, items, deliveryAddress, total);

        // Notify restaurant
        notificationService.notifyRestaurant(restaurantId, order.getOrderId());

        return order;
    }

    // Generic status transition with validation
    public void updateStatus(String orderId, OrderStatus newStatus) {
        Order order = orderRepo.findById(orderId).orElseThrow();
        if (!order.getStatus().canTransitionTo(newStatus)) {
            throw new InvalidStatusTransitionException(
                order.getStatus() + " → " + newStatus + " is not allowed"
            );
        }
        orderRepo.updateStatus(orderId, newStatus);
        onStatusChange(order, newStatus);
    }

    private void onStatusChange(Order order, OrderStatus newStatus) {
        switch (newStatus) {
            case CONFIRMED -> {
                // Assign nearest available delivery agent
                DeliveryAgent agent = agentService.findNearest(order.getRestaurantLocation());
                if (agent != null) {
                    orderRepo.assignAgent(order.getOrderId(), agent.getId());
                    notificationService.notifyAgent(agent.getId(), order);
                }
                notificationService.notifyCustomer(order.getCustomerId(), "Order confirmed!");
            }
            case READY_FOR_PICKUP -> notificationService.notifyAgent(
                order.getDeliveryAgentId(), "Order ready for pickup");

            case PICKED_UP -> notificationService.notifyCustomer(
                order.getCustomerId(), "Order is on the way!");

            case DELIVERED -> {
                notificationService.notifyCustomer(order.getCustomerId(), "Order delivered!");
                agentService.markAvailable(order.getDeliveryAgentId());
                paymentService.releaseFundsToRestaurant(order);
            }
            case CANCELLED -> {
                if (order.getDeliveryAgentId() != null)
                    agentService.markAvailable(order.getDeliveryAgentId());
                paymentService.refund(order.getCustomerId(), order.getTotalAmount());
            }
        }
    }

    // Cancel order — only allowed in early states
    public void cancelOrder(String orderId, String requestedBy) {
        Order order = orderRepo.findById(orderId).orElseThrow();
        if (order.getStatus() == OrderStatus.PICKED_UP || order.getStatus() == OrderStatus.DELIVERED)
            throw new CannotCancelException("Order already " + order.getStatus());
        updateStatus(orderId, OrderStatus.CANCELLED);
    }
}

// ── Delivery Agent Service ─────────────────────
class DeliveryAgentService {
    private final AgentRepository agentRepo;

    // Find nearest available agent using Haversine distance
    public DeliveryAgent findNearest(GeoLocation restaurantLocation) {
        return agentRepo.findAvailable().stream()
            .min(Comparator.comparingDouble(agent ->
                haversineDistance(restaurantLocation, agent.getLocation())))
            .orElse(null);
    }

    private double haversineDistance(GeoLocation a, GeoLocation b) {
        double R = 6371;  // Earth radius km
        double dLat = Math.toRadians(b.getLat() - a.getLat());
        double dLng = Math.toRadians(b.getLng() - a.getLng());
        double sinLat = Math.sin(dLat/2);
        double sinLng = Math.sin(dLng/2);
        double c = sinLat*sinLat + Math.cos(Math.toRadians(a.getLat()))
            * Math.cos(Math.toRadians(b.getLat())) * sinLng * sinLng;
        return 2 * R * Math.atan2(Math.sqrt(c), Math.sqrt(1-c));
    }
}
    State Machine as a Map: Encoding valid transitions in a Map<OrderStatus, Set<OrderStatus>> is cleaner than a switch/if-else. Adding a new state requires only updating the map — zero changes to existing transition code. The canTransitionTo() method is a single-line check.

    How do you test concurrent code?
    Use CountDownLatch to synchronize thread start (all threads wait at a barrier, then release simultaneously). Use CyclicBarrier for phases. Run with ExecutorService.   • Q
    When to use synchronized vs ReentrantLock?
    synchronized is simpler and sufficient for basic mutual exclusion. ReentrantLock when you need: tryLock with timeout, multiple condition variables, fairness guarantees, or ability to interrupt waiting threads. In most LLD problems, synchronized is fine unless you specifically need multiple conditions (like BoundedBlockingQueue).
  • Q
    How do you handle the Singleton pattern safely?
    Best: use an enum Singleton (enum MySingleton { INSTANCE; }) — guaranteed thread-safe by JVM, handles serialization. Second best: double-checked locking with volatile. Never use lazy initialization without synchronization in a multithreaded context.
